Optimización Numérica

Bisección · Newton · Secante a partir de f(x)

f'(x) = 0

Bisección

Requiere un intervalo [xl, xu] con cambio de signo en f'(x).

Tipo de entrada:

Escribes f(x). El sistema calcula f'(x) y f''(x).

Elige el tipo: si escribes f(x), se derivan f' y f''; si escribes f'(x), se integra F(x) con C=0 para graficarla. Usa * para multiplicar. Acepta sen, ln, e, ^.

Elige un método, llena los datos y presiona Calcular.

Aquí aparecerá el procedimiento con fórmulas y sustituciones.

Iter = iteración · xl = límite inferior · xu = límite superior · xr / x_i = aproximación · fp = f'(x) · fpp = f''(x) · ea = error (%).

Ambas usa doble eje Y. La vista 3D separa f(x) y f'(x) en dos superficies.

Eje x = valores de x. Curva verde = f(x) o F(x). Curva azul = f'(x). Línea punteada = f'(x)=0. Puntos naranjas = iteraciones. Estrella verde = x*.

Glosario

xl
Límite inferior del intervalo. Punto izquierdo.
xu
Límite superior del intervalo. Punto derecho.
xr
Punto medio (xl + xu)/2. Aproximación del punto crítico.
x_i / x(k)
Aproximación actual dentro de Newton o Secante.
x*
Punto crítico final donde f'(x*) ≈ 0.
Tipo de entrada
Elige f(x) o f'(x). Si escribes f(x), se derivan f' y f''. Si escribes f'(x), se integra F(x) con C=0 para graficarla.
f(x)
Función original. Se grafica en verde.
F(x)
Antiderivada de f'(x) cuando la entrada es la derivada. Solo para visualización, C=0.
f'(x)
Primera derivada. Resolver f'(x)=0 busca mínimos o máximos.
f''(x*)
Segunda derivada en x*. >0 mínimo, <0 máximo, ≈0 inconcluso.
fp
Abreviatura de f'(x) en las tablas.
fpp
Abreviatura de f''(x) en las tablas.
test
f'(xl)·f'(xr). Su signo decide qué mitad del intervalo se conserva.
ea (%)
Error relativo porcentual. Más pequeño = mejor aproximación.
Iter
Número de iteración.

Cómo leer la gráfica

  • Eje x: valores de x.
  • Eje y izquierdo: f(x). Eje y derecho: f'(x) cuando eliges Ambas.
  • Curva verde: f(x), la función original.
  • Curva azul: f'(x), calculada automáticamente.
  • Línea punteada: f'(x) = 0, donde buscamos el punto crítico.
  • Puntos naranjas: aproximaciones de cada iteración.
  • Estrella verde: x* final sobre la curva seleccionada.
  • Zona sombreada: intervalo inicial [xl, xu] en Bisección.
  • Selector Ambas / f(x) / f'(x): elige qué curvas mostrar.
  • Vista 3D: dos superficies separadas, una para f(x) y otra para f'(x).

Clasificación

  • f''(x*) > 0 → mínimo local.
  • f''(x*) < 0 → máximo local.
  • f''(x*) ≈ 0 → el criterio no decide.
